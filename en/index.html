Common questions

The aircraft symbol does not move. CockpitView needs GPS. Use an iPhone, or an iPad with cellular, allow location access, and sit by a window if you can.

No route or terrain in the air. Download the flight before you board (MCDU → INIT → DOWNLOAD*). Everything is then stored on the device and works in airplane mode.

The route differs from the one flown. The displays show the planned route, so the actual flight path can differ.

CockpitView is for entertainment. It is not a navigation aid or a certified instrument. Follow the crew's instructions on using devices on board.
